# 전투 준비 화면 와이어프레임 v1

작성일: 2026-11-13

이 문서는 최초 와이어프레임 기록이다. 이후 사용자 피드백에 따라 적 정보의 팝업 전환을 반영하고, PC 16:9 고정 구도와 시각 스타일을 적용한 [상점 디자인 v2](UI_SHOP_DESIGN_V2.md)를 작성했다. 아래의 상시 적 정보 배치와 좁은 화면에서의 세로 재배치는 최신 시안에서 사용하지 않는다.

## 사용자가 선택한 기준

- PC, 마우스·키보드, 가로 화면.
- 가방 배치와 아이템 정보의 가독성을 우선한다.
- 단순한 색과 도형으로 배치와 조작부터 검토한다.

## 이번 초안의 범위

대화에서 조작할 수 있는 전투 준비 화면 시안이다. Unity 게임 코드나 실제 저장 데이터에 연결되지 않는다. 아이템 종류·수치·가격·배치는 화면 검토용 예시이며, 밸런스 또는 레시피 변경안이 아니다.

| 영역 | 배치와 의도 |
|---|---|
| 상단 | 스테이지·라운드, 런 골드, 라이프, 설정을 함께 표시 |
| 왼쪽 | 상점 4개 상품, 할인·상품 유지 잠금, 리롤, 판매 영역 |
| 중앙 | 6×6 가방을 가장 큰 조작 대상으로 배치하고 전투 사용 여부 명시 |
| 오른쪽 | 다음 적 이름·일러스트 자리·체력·주요 장비와 전투 시작 |
| 하단 | 가방과 인접한 자유 보관함. 전투 미참여와 개수 제한 없음을 표시 |
| 최하단 | 스테이지 포기와 짧은 행동 결과/실패 안내 |

현재 게임은 상점 영역 전체를 판매 영역으로 사용한다. 이번 시안의 별도 판매 표시는 판매 위치를 알아보기 쉽게 만드는 제안이다. 실제 드롭 판정을 별도 영역으로 바꿀지는 이후 검토한다.

## 비교할 상태

1. 기본: 상품·가방·적 정보를 한 번에 확인.
2. 드래그: 칸 위에서 배치 가능/불가를 구분. 실제 상품을 가방이나 보관함에 드래그하면 예시 구매 결과를 반영.
3. 툴팁: 아이템 이름·등급·수치·효과·점유 크기 표시. 클릭하면 고정해서 읽고 닫을 수 있음.
4. 골드 부족: 부족한 상품의 가격/테두리와 하단 안내 강조. 골드 0에서는 리롤 비활성.
5. 합성 예정: 관련 가방 아이템과 예상 결과를 강조하고, 전투 후 상점 복귀 시 보관함으로 간다는 시점 표시.

툴팁 클릭 고정과 상점 잠금 아이콘 클릭은 접근성을 위한 시안상의 대안이다. 기존 게임의 호버·우클릭 조작과 함께 채택할지는 검토가 필요하다.

## 초안의 조작 범위

- 구현: 상태 전환, 아이템 상세, 상품 잠금 표시, 예시 드래그 구매/배치·보관, 포기 확인창.
- 연결 위치만 표시: 새로고침, 전투 시작, 설정, 포기 후 메인 이동.
- 이번 초안에서 재현하지 않음: 보유 아이템 이동·판매·회전, 실제 합성 판정, 전투 계산, 영구 저장.
- 위의 상태 버튼은 시안 검토 도구이며 게임 UI에 들어가는 버튼이 아니다. 상태를 바꾸면 예시 배치와 재화를 초기화한다.
- 좁은 대화창에서는 내용을 세로로 배치한다. 이는 검토 화면의 대응이며 모바일 출시 UI 설계가 아니다.

## 다음 검토 항목

- 가방을 조작할 때 충분히 크게 느껴지는가?
- 상점 → 가방 → 보관함의 시선/드래그 이동이 자연스러운가?
- 오른쪽 적 정보와 전투 시작 버튼의 비중이 적절한가?
- 툴팁이 가방을 가리는 정도가 괜찮은가, 가방 밖에 두는 편이 나은가?
- 자유 보관함과 판매 영역을 혼동하지 않는가?

배치 방향을 정한 뒤 실제 1280×720 게임 화면 기준의 여백·텍스트·히트 영역을 확정하고 전투 화면 와이어프레임으로 이어간다. 색상·장식·최종 아이콘·캐릭터 아트 적용은 그 다음 단계다.
