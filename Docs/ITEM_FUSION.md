# 아이템 합성

`Assets/_Project/Data/Recipes/Recipe_SteelSword.asset`가 첫 레시피입니다. 중심 재료는 훈련용 검, 추가 재료는 숫돌 1개, 결과는 강철 검입니다.

강철 검: 고급, 1×3, 공격력 8, 사용 주기 1.8초, 명중률 95%, 치명타 확률 15%, 치명타 피해 200%. 기준 가격 6G, 판매가 3G. `Exclude From Shop`을 켜서 상점 추첨에서 제외합니다. 카탈로그에 실수로 추가해도 추첨되지 않습니다.

## 플레이 규칙

- 가방에서 중심 아이템의 실제 점유 칸과 재료가 상하좌우로 맞닿아야 합니다. 대각선만 접한 경우는 제외됩니다. 재료가 여러 개라면 각 재료가 중심 아이템에 직접 맞닿아야 합니다.
- 전투 시작 시 합성 대상을 확정하고, 전투 종료 후 상점 복귀 시 한 번 처리합니다. 해당 전투는 원래 재료들의 스탯/배치 효과로 진행합니다. 승리 후 다음 라운드뿐 아니라 라이프가 남은 패배(90초 강제 패배 포함) 후 상점 복귀에도 적용합니다. 최종 클리어/게임 오버에는 상점 복귀가 없어 합성을 실행하지 않습니다. 명시적으로 이른 시간 제한을 지정한 시뮬레이션 테스트의 무승부 후 복귀도 계속 지원합니다.
- 준비 화면의 `테스트 다음` 버튼은 전투를 하지 않으므로 합성을 실행하지 않습니다.
- 보관함과 상점 재료는 참고 연결선에만 사용하며 자동 합성으로 소비하지 않습니다.
- 결과는 모두 보관함으로 이동하고 중심 아이템의 회전을 유지합니다. 가방의 빈 공간과 결과 아이템의 크기는 합성 조건이 아닙니다.
- 동일 재료는 한 번만 사용합니다. 겹치는 후보는 레시피 목록 순서, 중심 아이템의 위→아래/왼쪽→오른쪽 순서로 우선 선택합니다. 선택된 합성만 노란색으로 표시합니다. 이번에 만든 결과는 같은 복귀 시점에 연쇄 합성되지 않습니다.

## 표시와 잠금

- 재료에 마우스를 올리면 같은 레시피의 다른 재료를 가방·보관함·상점에서 찾아 회색 선으로 연결합니다. 일부 재료만 모여도 참고 선은 보이며 구매 완료 상품은 제외됩니다.
- 실제 합성이 예약될 조합은 마우스 위치와 관계없이 굵은 노란 선과 결과 이름으로 표시합니다. 선은 둥근 끝과 투명한 가장자리를 사용하며, 긴 선은 완만하게 휘어집니다. 회색 참고선은 초기 부드러운 선 대비 본체와 가장자리 폭을 0.7배로 줄였으며 약 0.12초간 페이드 인/아웃합니다. 노란 선에는 은은한 광채가 있습니다. 전투 화면·드래그·합성 연출 중에는 선을 숨깁니다.
- 가방/보관함의 재료에 `Shift + 우클릭`하면 합성 잠금/해제합니다. 노란 자물쇠를 이름표와 같은 아이템 중앙에 겹치되, 그리기 순서는 아이템 외형 → 자물쇠 → 이름표입니다. 이름표를 제거해도 자물쇠는 같은 위치에 남습니다. 잠긴 재료가 포함된 조합은 예약되지 않으며 마우스를 올릴 때 회색 참고 선만 표시합니다.
- 잠금은 개별 소유 아이템에 적용하고 보관함↔가방 이동에도 유지합니다. 공격/배치 효과/판매에는 영향을 주지 않습니다. 상점 우클릭은 기존 상품 유지 잠금입니다.
- 아이템 툴팁에는 원래 스탯·배치 효과·설명만 표시하며 합성 레시피, 잠금 상태, 도움말과 조작 안내를 추가하지 않습니다.

## 합성 연출과 보관함

상점 복귀 시 `Fusion` 단계로 진입합니다. 상점은 표시되지만 구매·판매·드래그·리롤·회전·잠금·라운드 이동·전투 시작과 툴팁은 비활성화됩니다.
추가 재료가 중심으로 모여 작아진 뒤 빛과 함께 결과가 나타나고, 곡선을 따라 보관함으로 이동한 후 짧게 강조됩니다.
한 조합은 약 1.32초이며 여러 조합은 최대 0.4초의 시차를 두고 함께 연출합니다. 연출은 unscaled time을 사용하므로 `Time.timeScale = 0`이어도 끝납니다.

재료 검증 후 재료 소비와 보관함 결과 지급을 한 번 확정하고, 실제 결과 뷰는 도착할 때까지 숨깁니다. 연출은 별도 시각 복사본을 사용합니다.
컨트롤러가 비활성화되어 연출이 중단되면 결과를 보관함에 즉시 표시하고 준비 상태로 복귀합니다. 결과를 중복 지급하거나 재료로 되돌리지 않습니다.

보관함 위치는 기존 아이템과 겹치지 않는 곳을 우선 탐색합니다. 이미 가득 찼으면 겹침이 가장 적은 위치를 사용하며 수량 제한으로 합성을 취소하지 않습니다.
보관함보다 큰 결과도 중앙에 보관할 수 있으며, 기존 자유 보관함처럼 경계 밖으로 보일 수 있습니다. 보관함은 그리드가 아니며 기존 아이템 위치는 바뀌지 않습니다.

## 새 레시피 제작

1. `Create > Backpack AutoBattle > Fusion Recipe`로 SO를 만듭니다.
2. `Center Item`에 중심 재료, `Ingredients`에 추가 재료와 `Quantity`, `Result Item`에 결과 ItemData를 지정합니다. 중심은 목록에 다시 넣지 않습니다. 같은 종류의 추가 재료가 필요할 때만 해당 종류를 추가합니다.
3. 씬의 `Backpack Prototype` 컴포넌트 `Fusion Recipes` 배열에 등록합니다. 위쪽 레시피부터 우선 적용됩니다.
4. 합성 전용 결과 ItemData에는 `Exclude From Shop`을 켭니다.

레시피의 이름/재료/수량을 바꾸면 예약 조합과 연결선에 반영됩니다. 전투 중 콘텐츠 SO 편집은 지원하지 않으며 Play를 종료한 뒤 수정하는 것을 권장합니다.
