후속 제작 원칙(2026-11-06): 아래 20종은 작성 당시의 스냅샷이며 고정 제작 목록이 아니다. 사용자가 각 제작 때 지정하는 아이템의 최신 에셋·점유 칸·외형 요청을 다시 확인한다. 추가·삭제·외형 변경은 그 시점의 정보를 따른다. 기사의 보검과 은빛 장궁의 후속 생성 기록은 [별도 문서](knight-sword-silver-longbow-2026-11-06-v1.prompt.md)에 있다.

## 참고 자료와 적용 범위

- 사용자 첨부 이미지 1~3: 아이템의 도트 표현, 외곽선, 색면, 재질, 작은 크기에서의 가독성을 참고한다. 화면 배경, 격자, 도감 UI, 캐릭터는 생성 대상이 아니다.
- 프로젝트 설계·구현 문서: [개발 시작점](../DEVELOPMENT_START.md), [아이템 합성](../ITEM_FUSION.md), [메인 화면과 고유 장비](../MAIN_MENU.md), [상태 효과](../STATUS_EFFECTS.md).
- 실제 형태의 기준: `Assets/_Project/Data/Items/Item_*.asset` 18종과 `Assets/_Project/Data/Enemies/Items/Item_*.asset` 2종의 `_occupiedCells`, `_canRotate`.
- 좌표·회전의 기준: `Assets/_Project/Scripts/Core/Inventory/ItemShape.cs`, `ItemRotation.cs`. 좌상단 원점, x는 오른쪽, y는 아래쪽, 90도 단위 시계 방향 회전 후 좌상단으로 정규화한다.
- 기존 캐릭터·몬스터 아트 문서는 대상이 다르다. 이번 아이템의 도트 밀도와 구도는 사용자가 이번에 제공한 세 이미지에 맞춘다.

이름·점유 모양·회전 가능 여부·명시된 재질은 프로젝트 사실이다. 아래의 보석, 문양, 금속 테두리, 부적 구조 등은 아직 외형이 정해지지 않은 아이템에 대한 제안이다. `_displayColor`는 현재 임시 칸 표시에도 쓰이므로 최종 재질색의 강제 규칙으로 해석하지 않는다. 예를 들어 훈련용 검의 표시색은 파랑이지만 실제 설명은 목검이다.

## 그림체 해석

- 저해상도 판타지 RPG의 인벤토리용 픽셀 아트. 작은 크기에서도 무기·방어구·병·장신구가 실루엣으로 구분된다.
- 선명하게 보이는 사각 픽셀과 계단형 곡선. 둥근 벡터 윤곽이나 매끈하게 축소한 고해상도 일러스트 느낌은 피한다.
- 짙은 보라·갈색·남색 계열의 어두운 외곽선과 재질별 색면. 검정 외곽선으로 모든 면을 두껍게 둘러싸기보다 외곽과 겹침을 읽히게 한다.
- 밝음·중간·어두움의 3~4단계 명암을 기본으로 제안한다. 금속에는 짧고 밝은 하이라이트, 나무에는 큰 갈색 면과 최소한의 결, 유리에는 흰 반사점과 선명한 액체색을 쓴다.
- 기본 재질은 차분한 갈색·회색으로, 마법·독·불·보석은 명확한 포인트색으로 표현한다. 미세한 잡티와 과한 디더링을 줄인다.
- 정면 또는 측면에 가까운 아이콘 구도. 얕은 두께감은 허용하지만 원근으로 아이템 길이가 줄거나 인벤토리 모양이 흐트러지지 않게 한다.
- 이미지 한 장에는 아이템 한 종류만 담는다. 쌍도끼의 두 도끼는 하나의 아이템 세트다.

## 공통 생성 프롬프트

다음 공통 문구에 아래 형태 규칙과 해당 아이템의 개별 문구를 이어 붙인다. 생성할 때 첨부 이미지 1~3을 스타일 참고 이미지로 함께 제공한다.

```text
Use case: stylized-concept
Asset type: 판타지 가방 자동 전투 게임의 인벤토리 아이템 스프라이트

첨부 이미지 1~3의 아이템 표현을 참고하여 아래 지정된 아이템 한 종류를 그린다.
큼직하고 선명한 사각 도트, 계단형 윤곽, 어두운 유채색 외곽선,
간결한 색면과 3~4단계 명암을 사용하는 저해상도 판타지 RPG 픽셀 아트.
작게 보아도 종류와 재질이 즉시 읽히는 과장된 실루엣과 절제된 디테일.
광원은 좌상단으로 통일하고 금속·나무·가죽·유리를 간결하게 구분한다.
정면 또는 측면에 가까운 구도로 전체 아이템을 자르지 않고 보여 준다.
아이템 사이에 도트 크기와 외곽선 굵기가 일관되게 느껴지도록 한다.

아래 점유 칸 좌표와 모양을 반드시 따른다.
아이템의 주요 부분을 각 점유 칸에 배치하고, 인접한 점유 칸 사이는 자연스럽게 연결한다.
점유 모양은 허용 영역이며 사각 블록을 빈틈없이 칠하라는 뜻이 아니다.
비점유 칸에는 윤곽선·그림자·끈·불꽃·입자까지 아무것도 그리지 않는다.
지정된 기본 방향을 유지하고 임의 회전·좌우 반전·대각선 배치를 하지 않는다.
투명한 전체 캔버스와 비점유 칸의 위치를 보존한다.

배경은 실제 알파 투명. 아이템 자체의 외곽선과 내부 명암만 포함한다.
참고 화면의 보라색 바탕, 격자, 슬롯 테두리, 아이템 이름, 글자, 숫자,
UI, 희귀도 프레임, 워터마크, 바닥 그림자는 그리지 않는다.
사진, 3D 렌더, 부드러운 그라데이션, 블러, 안티앨리어싱으로 흐려진 도트,
연무형 발광, 캔버스 밖으로 나가는 효과, 여러 아이템을 모은 시트는 피한다.
```

## 형태 지정 규칙

- 크기는 모두 **가로 칸 수 × 세로 칸 수**다. `#`는 점유, `.`는 비점유, `/`는 다음 행이며 위에서 아래로 읽는다.
- 좌표는 `(x,y)`이고 `(0,0)`이 좌상단이다. 점유 수는 바운딩 박스 면적이 아니라 좌표 개수다.
- 한 칸을 정사각형 S×S로 잡으면 캔버스는 W×S, H×S다. 비점유 칸은 알파 0을 유지한다. 예: 3×2 T자는 6칸 크기의 캔버스에서 4칸만 사용한다.
- 모든 점유 칸에 식별 가능한 본체 일부가 있어야 한다. 다만 활 안쪽 공간, 손잡이 양옆 등은 점유 칸 안에서도 투명할 수 있다.
- 빈칸을 피하려고 완성된 직사각형 그림을 잘라내기보다, 처음부터 칸 구조에 맞게 본체를 설계한다. 마스크 검수는 필요하지만 본체의 잘못된 구조를 해결하지는 못한다.
- 기본 방향 1장으로 설계한다. 회전 가능한 아이템은 게임에서 본체와 점유 형태를 함께 회전시키는 것을 전제로 한다. 별도 회전 그림은 현재 범위에 포함하지 않는다.
- 도트 밀도의 출발점으로 한 칸당 논리 해상도 24~32px 정도를 제안한다. 이는 참고 이미지에서 확정 측정한 값이나 현재 프로젝트의 필수 출력 규격이 아니다. 실제 생성·축소 검수 후 정한다.
- 현재 상점 UI의 `CellPitch = 54`, `ItemCellSize = 48`은 화면 배치 값이다. 그림을 칸마다 끊거나 그 틈을 스프라이트에 그려 넣는 규칙으로 사용하지 않는다.

개별 프롬프트에 붙일 형태 지시문:

```text
아이템: {이름 / ID}
기본 방향 캔버스 비율: {W}:{H}, 정사각형 셀 기준 {W}×{H}.
점유 칸 수: {N}. 좌상단 원점의 점유 좌표: {좌표 목록}.
행별 점유 마스크: {마스크}. #는 허용 영역, .는 완전 투명 영역.
아래 개별 설명대로 각 부분을 배치하고, 비점유 칸에는 효과도 침범하지 않는다.
```

## 아이템별 추가 프롬프트

아래 문구는 공통 프롬프트 및 표의 형태 지시문과 결합해서 사용한다. 문양은 물체에 새겨진 단순 그림으로 표현하고 읽을 수 있는 문자나 UI 표식은 넣지 않는다.

### 01. 훈련용 검 — training_blade

1×3 세로 목검. 칼끝은 위, 손잡이는 아래. 위쪽 두 칸에 긴 나무 칼날, 아래 칸에 작은 가드와 천을 감은 손잡이를 배치한다. 밝은 황갈색 나무와 짙은 갈색 결 몇 줄, 약간 둥근 칼끝으로 소박한 훈련 장비를 표현한다. 가드도 한 칸 폭을 넘지 않는다. 원본 설명의 목검 재질을 유지한다.

### 02. 철 단검 — iron_dagger

1×2 세로 단검. 위 칸은 짧고 넓은 철제 칼날, 아래 칸은 작은 가드와 갈색 손잡이. 차가운 회색 칼날에 청록빛 반사색을 약하게 넣는다. 짧고 실용적인 근접 무기로 표현하고 장검처럼 길게 늘이지 않는다.

### 03. 쌍도끼 — throwing_axes

2×1 가로 영역 안에 짧은 투척 도끼 두 자루를 한 세트로 배치한다. 왼쪽 칸과 오른쪽 칸에 각각 도끼 머리와 짧은 손잡이가 읽히게 하고, 중앙에서 손잡이를 살짝 포개 하나의 묶음처럼 보이게 한다. 회색 날, 황갈색 목재, 주황빛 가죽 끈. 두 칸 높이가 필요한 큰 X자 구도를 만들지 않는다.

### 04. 화염 지팡이 — fire_staff

3×2 캔버스의 4칸 T자 지팡이. 윗줄 세 칸을 가로지르는 낮고 넓은 금속 머리 장식과 그 안에 모인 붉은 주황 불꽃을 그린다. 중앙 머리에서 내려오는 짧은 자루와 손잡이는 아래 중앙 칸에만 둔다. 불꽃도 윗줄 안에 머무른다. 아래 왼쪽과 아래 오른쪽 칸은 완전히 투명하게 유지한다. 긴 일자 봉으로 바꾸지 않는다.

```text
###
.#.
```

### 05. 나무 방패 — wooden_shield

2×2 네 칸에 걸친 넓은 원형에 가까운 나무 방패 정면. 큰 목판 면, 회색 금속 테두리와 중앙 보스로 튼튼한 방어구를 표현한다. 위와 아래가 모두 충분히 넓고 네 칸에 본체가 걸쳐 있어야 한다. 둥근 외곽의 모서리 여백은 투명하게 남겨 자연스러운 방패 실루엣을 유지한다.

### 06. 가시 갑옷 — thorn_armor

2×2 네 칸에 걸친 짙은 녹색 계열 금속 흉갑. 위 두 칸은 어깨와 가슴, 아래 두 칸은 몸통과 허리판. 어깨와 옆면에 크고 적은 수의 가시를 넣되 모든 가시는 허용 영역 안에 둔다. 회녹색 금속 하이라이트와 어두운 가죽 연결부로 재질을 구분한다. 착용자와 팔다리는 그리지 않는다.

### 07. 신속의 부적 — swift_charm

### 09. 회복 물약 — healing_potion

1×1 안에 작은 코르크 마개와 둥근 유리 몸통이 모두 들어가는 붉은 회복 물약. 밝은 빨강 액체, 어두운 적색 그림자, 한두 군데 흰 반사점으로 표현한다. 짧은 목과 통통한 몸통으로 작은 화면에서도 병으로 읽히게 한다. 라벨 글자는 없다.

### 10. 숫돌 — whetstone

1×1 안의 작은 회색 숫돌. 약간 비스듬히 놓인 납작한 직육면체에 밝은 윗면, 중간 밝기 옆면, 짙은 아랫면을 준다. 모서리 마모와 손질 자국은 몇 개의 큰 도트로만 표현한다. 인접 무기나 좌우 효과 범위, 화살표는 그리지 않는다.

### 11. 정밀의 부적 — precision_charm

1×1의 각진 금속 부적. 녹색 보석 중심에 짧고 날카로운 주황빛 반짝임을 넣고, 네 방향으로 각진 테두리를 구성하여 정확한 치명타의 인상을 준다. 긴 목걸이 줄 없이 작은 고리만 포함한다. 집중의 부적과 구별되도록 각진 실루엣을 사용한다.

### 12. 집중의 부적 — focus_charm

1×1의 둥근 녹색 보석 메달. 은색 동심 테두리와 중심의 흰 빛점으로 한곳에 집중하는 느낌을 표현한다. 큰 원형 면과 차분한 대칭 구도를 유지하고, 정밀의 부적보다 둥글고 안정적인 외형을 사용한다. 문자는 없다.

### 13. 민첩의 부적 — agility_charm

1×1의 가벼운 청록색 날개 모양 금속 부적. 한쪽으로 휘어지는 짧은 깃털 실루엣과 밝은 하늘색 보석, 작은 은색 연결 고리. 단순한 날개 형태로 회피와 가벼움을 나타내고, 속도선이나 외부 잔상으로 크기를 늘리지 않는다.

### 14. 흡혈의 부적 — vampiric_charm

1×1의 붉은 물방울 보석 부적. 짙은 적색 보석을 두 개의 짧은 상아색 송곳니 장식이 감싸고, 어두운 금속 고리가 위에 붙는다. 보석의 큰 빨간 면과 밝은 송곳니로 흡혈 속성을 읽히게 한다. 피가 튀는 효과 없이 장신구 자체만 그린다.

### 15. 실명의 가루 — blinding_dust

1×1 안에 들어가는 입구를 묶은 작은 남보라색 가루 주머니. 천의 큰 주름과 검보라색 가루 몇 알을 묶인 입구 바로 옆에 표현한다. 주머니와 가루 모두 한 칸 안에 들어가고, 넓은 연막이나 주변을 덮는 구름은 만들지 않는다. 병 형태의 물약과 명확히 구분한다.

### 16. 강철 검 — steel_sword

1×3 세로 강철 검. 위쪽 두 칸은 곧고 반듯한 회청색 강철 칼날, 아래 칸은 작은 금속 가드와 짙은 가죽 손잡이. 훈련용 목검에서 강화된 재질 차이가 분명하게 보이도록 밝은 날끝 하이라이트를 준다. 장식은 절제하고, 기사의 보검보다 단순한 실용 무기로 표현한다.

### 17. 기사의 보검 — knight_sword

1×3 세로 기사 검. 은회색의 곧은 칼날과 정돈된 가드, 남청색 손잡이, 작은 푸른 보석을 가진 소박한 고유 무기. 위쪽 두 칸에 칼날, 아래 칸에 가드와 손잡이를 둔다. 강철 검과 구별되는 작은 장식을 허용하되 시작 장비에 맞게 과도한 금장·왕관·발광은 피한다. 가드의 너비도 한 칸 안에 맞춘다.

### 18. 은빛 장궁 — silver_longbow

1×3 세로로 길고 폭이 좁은 은빛 활. 위·중앙·아래 칸을 잇는 완만한 곡선의 활대, 중앙의 짙은 갈색 손잡이, 위아래 끝을 연결하는 팽팽한 시위를 그린다. 은백색 몸체에 작은 금빛 연결 장식을 넣는다. 활대와 시위의 최대 폭은 한 칸 안에 들어가야 한다. 활 내부의 투명한 공간은 남긴다. 화살을 가로로 끼우거나 추가 칸을 차지하게 하지 않는다.

### 19. 고블린 몽둥이 — goblin_club

1×2 세로 나무 몽둥이. 위 칸에 굵고 울퉁불퉁한 타격부, 아래 칸에 가늘어지는 손잡이와 해진 가죽 감개를 둔다. 거친 황갈색 목재와 짙은 갈색 패임 몇 개로 고블린의 조악한 무기를 표현한다. 훈련용 목검과 달리 굵은 둥근 머리와 비대칭 윤곽을 사용한다.

### 20. 빙결 시험 부적 — goblin_frost_charm

1×1 안에 푸른 얼음 결정이 달린 작은 부적. 짧고 각진 하늘색 결정, 흰색 하이라이트, 짙은 파랑 음영과 간단한 어두운 연결 고리. 뻗어나가는 얼음 가시와 냉기 안개 없이 한 칸 안의 작은 장신구로 표현한다. 시험 아이템이라는 이름은 그림에 쓰지 않는다.

## 향후 생성 결과의 검수 기준

1. 표의 기본 방향, 점유 수, 빈칸 위치를 실제 에셋과 다시 대조한다. 프롬프트만으로 생성 결과의 픽셀 단위 마스크 준수를 보장할 수는 없다.
2. 비점유 셀의 알파가 모두 0인지 확인한다. 윤곽선·발광·그림자도 예외 없이 점검한다.
3. 모든 점유 칸에 본체의 의미 있는 부분이 있고, 하나의 아이템으로 읽히는지 확인한다. 쌍도끼는 두 자루 한 세트로 확인한다.
4. 마스크를 자르기 전에 장신구·병·지팡이의 구조가 자연스러운지 확인한다. 잘못된 구조는 재구성한다.
5. 도트 크기, 외곽선, 팔레트, 재질 표현이 세 참고 이미지의 방향과 일관되는지 작은 표시 크기에서 확인한다.
6. 최종 PNG의 투명 여백과 전체 W:H 캔버스를 보존한다. 비대칭 아이템을 자동 중앙 정렬하거나 불투명 영역만으로 타이트 크롭하지 않는다.
7. 현재 `PrototypeItemShapeVisual`은 점유 칸 색상과 이름으로 그리는 구현이다. 이 문서 작성은 스프라이트 표시 구현이나 임포트 설정 변경을 포함하지 않는다.
