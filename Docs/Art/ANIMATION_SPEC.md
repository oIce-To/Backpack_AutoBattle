# 일러스트 표시 및 피격 효과

2026-11-17 변경: 사용자가 인게임에서 원본 대비 그림 품질과 표시 크기 차이를 확인하여, 대기·공격 프레임 애니메이션의 Unity 적용을 취소했다. **기존 확정 스탠딩 일러스트를 그대로 사용하고 피격 시 좌우 흔들림만 유지한다.**

## 현재 적용 범위

- 메인 화면·상점·전투 모두 기존 CharacterData.Portrait / EnemyData.Illustration을 표시한다.
- 대기·공격 프레임 교체, 프레임 시트 로드, 별도 크기/배율/방향 보정은 제거했다.
- 원본 PNG와 Unity 임포트 설정을 변경하지 않는다. 표시 영역과 방향은 애니메이션 적용 이전 코드와 동일하다.
- 직접 공격하는 무기·펫이 명중해 체력 또는 방어도에 피해를 주면 대상 일러스트만 좌우로 흔든다.
- 방어도가 전부 흡수해도 체력 피해와 같은 강도다. 회피·빗나감·무적으로 적용 피해가 0이면 흔들리지 않는다.
- 중독·화상 등 지속 피해와 공격 외 아이템 효과는 이 피격 효과를 재생하지 않는다.
- 피격은 0.15 전투 초 동안 최대 6 UI 단위 이내에서 감쇠하는 가로 흔들림이다. 세로 위치, 스프라이트, 크기, 배율을 변경하지 않는다.
- 연속 피격은 최신 피격 시점으로 갱신하며 이동량을 누적하지 않는다.
- 전투 시계 기준으로 재생하므로 일시정지·배속을 따른다. 종료·초기화·다음 전투에서는 원래 위치로 복귀한다.

## 구현

- `Assets/_Project/Scripts/Prototype/PrototypeIllustrationHitFeedback.cs`: 위치만 변경하는 피격 효과.
- `PrototypeBattleScreen`: 직접 공격 이벤트의 대상에게 피격을 전달하고 전투 시간으로 갱신한다.
- 메인·상점 표시 코드 및 기존 원본 일러스트 검증 테스트는 프레임 적용 전으로 복원했다.
- `Resources/IllustrationAnimations`와 프레임 재생 코드/테스트를 제거했다.

## 과거 시안

`Docs/Art/AnimationPilot/`은 Unity 적용 전에 만든 비교용 시안과 프롬프트 기록으로만 보존한다. 게임에서 로드하지 않으며 현재 적용본이나 후속 제작 승인 기준으로 취급하지 않는다. 나머지 몬스터의 대기·공격 프레임 확대 작업도 보류한다.

## 복원 검증

Unity 6000.3.17f1 PlayMode 관련 테스트 18개 통과. 원본 스프라이트·표시 크기·방향 유지, 무기/펫 직접 피해와 방어도 흡수의 동일한 흔들림, 빗나감/피해 0/공격 외 효과 제외, 정지·배속·위치 복귀를 확인했다. 메인·상점·전투를 실제 렌더링으로 캡처해 기존 스탠딩 일러스트가 표시되는 것도 확인했다. 결과는 `Logs/HitFeedbackQA/results.xml`에 저장했다.
