# 외부 능력치와 화상·중독

## 스테이지 진입 능력치

`Assets/_Project/Data/Character_Default.asset`의 최대 체력 50, 공격력 10을 기본값으로 사용한다.
씬의 Backpack Prototype → Character Data가 이를 참조한다. Play 시작 시 이름과 능력치를 런에 복사하며,
그 후 캐릭터 SO를 변경하거나 연결 대상을 교체해도 진행 중인 12라운드에는 반영하지 않는다.
다른 캐릭터/영구 성장/메인 화면/저장은 아직 구현하지 않았다. 향후 해당 화면에서 확정한 값을
`CharacterStatsSnapshot`으로 전달하면 같은 계산 경로를 사용할 수 있다.

## 순수 비례 수치

`StatScaling`에서 Stat과 Coefficient를 설정한다. Attack/Maximum Health는 **해당 능력치 × 계수**만 계산하며 고정값을 더하지 않는다.
Fixed는 기존 데이터/명시적 적 수치의 호환 모드이며, 현재 플레이어 아이템의 피해·방어도·숫돌 효과는 비례 모드다.
고정 모드의 기존 필드는 비례 모드에서는 무시된다. 사용 주기, 명중/치명타 관련 확률, 상태 부여 중첩 수는 이 공격력 계수와 별개다.

| 데이터 | 참조 능력치 | 계수 | 기본 캐릭터에서의 결과 |
| --- | --- | --- | --- |
| 훈련용 검 | 공격력 | 0.5 | 공격력 5 |
| 철 단검 | 공격력 | 0.2 | 공격력 2 |
| 쌍도끼 / 강철 검 | 공격력 | 0.8 | 공격력 8 |
| 화염 지팡이 | 공격력 | 1.2 | 공격력 12 |
| 숫돌의 공격력 보너스 | 공격력 | 0.1 | +1 |
| 나무 방패의 방어도 획득 | 최대 체력 | 0.05 | 2초마다 +2.5 |
| 화상 1중첩의 주기 피해 | 부여자의 기준 공격력 | 0.12 | 매초 1.2 |
| 중독 1중첩의 주기 피해 | 부여자의 기준 공격력 | 0.1 | 매초 1 |

아이템 공격력은 Attack Scaling, 방어도는 Activation → Effects → Amount Scaling,
숫돌은 Placement Effects → Attack Scaling에서 설정한다.
화상·중독은 Status_Burn / Status_Poison SO에서 Damage Scaling, Tick Interval Seconds,
Stacks Lost Per Tick를 설정한다. 기본값은 주기 1초, 화상 감소 1, 중독 감소 0이다.

상점/보관함/가방 툴팁과 전투 스냅샷이 동일한 수치 해석 경로를 사용한다.
플레이어 화면에는 계수나 기준 공격력 설명을 추가하지 않고, 계산을 마친 수치만 표시한다.
전투 중 변화의 초록/빨강 비교 기준도 캐릭터 능력치를 반영한 아이템 기본 수치다.
SO와 전투 스냅샷은 분리되므로 전투 중 수치 변경이 원본 아이템에 누적되지 않는다.

## 적과 라운드

Enemy Encounter의 Attack은 해당 적의 기준 공격력이며 기본값은 10이다.
Stage의 각 Round → Overrides → Attack을 체크하면 그 라운드만 덮어쓴다.
체력은 기존 Maximum Health 덮어쓰기를 그대로 사용한다.

적 기준 체력·공격력 확정 → 장비의 계수 계산 → Encounter의 개별 장비 덮어쓰기 →
Round의 개별 장비 덮어쓰기 → 전투 배치 효과/상태 보정 순서다.
개별 장비의 Attack Damage 덮어쓰기는 계수가 아니라 최종 공격력이다.
고블린 몽둥이는 기준 공격력의 50%이며 기존 라운드의 장비 덮어쓰기는 유지했다.
같은 아이템 SO라도 플레이어와 적은 각각 자신의 능력치를 사용한다.

## 지속 피해 규칙

- 처음 부여된 때로부터 1초 뒤 첫 피해가 발생한다. 중첩 추가는 다음 피해 시점을 밀지 않는다.
- 중첩이 전부 제거되면 기존 시계도 제거되며, 다시 부여하면 새 1초 주기를 시작한다.
- 화상은 현재 중첩으로 피해를 적용한 뒤 전체 중첩에서 1을 뺀다. 중독은 자연 감소하지 않는다.
- 부여자의 스테이지 진입/적 전투 구성 기준 공격력을 사용한다. 피격자의 공격력이나 무기의 전투 중 공격력 보너스를 참조하지 않는다.
- 출처가 여러 개인 중첩은 출처별 피해량을 보존한다. 자연 감소/정화는 먼저 들어온 출처의 중첩부터 제거한다.
- 신속·빙결은 부여 아이템의 사용 주기에는 적용되지만 화상·중독의 피해 주기에는 적용되지 않는다.
- 상태 피해는 명중/회피/치명타를 판정하지 않는다. 방어도를 먼저 소모하고 남은 피해를 HP에 적용한다.
- 피해 분류는 StatusEffect이며 회피 이벤트를 발생시키지 않는다. 이후 가시/흡혈은 AttackItem 피해만 구독하도록 구분할 수 있다.
- 중첩은 64비트 정수이고 게임상 상한이 없다. 피해는 소수를 보존하며 표시를 위해 정수로 잘라 계산하지 않는다.
- 아이템과 지속 피해는 하나의 시간순 처리에 들어간다. 정확히 같은 시각이면 기존 아이템 발동을 먼저,
  지속 피해끼리는 대상(Player → Enemy), 종류(Burn → Poison) 순으로 처리한다.

기존 비례 효과 상태 아이콘/툴팁 색상은 유지했다. 화상은 주황색 불꽃, 중독은 연두색 물방울이다.
툴팁에는 현재 중첩으로 인한 실제 주기 피해와 자연 감소만 짧게 표시한다.
전투 로그도 아이템 발동과 지속 피해가 시간순으로 기록된다.

## 인게임 테스트

기존 화염 지팡이에 3.5초마다 상대에게 화상 2, 맹독 약병에 3초마다 상대에게 중독 2를 연결했다.
이는 임시 검증 수치이며 SO에서 조정할 수 있다. 화염 지팡이의 상태 부여는 직접 공격의 명중 여부와 별개의 주기 효과다.
두 아이템 모두 기존 상점 카탈로그에 있으므로 새 상품을 추가하지 않았다.

1. Character_Default SO의 체력/공격력을 설정한 뒤 Play를 시작한다.
2. 나무 방패 툴팁과 체력을 확인한다. 기본값에서 방어도 2.5, 최대 체력 50이어야 한다.
3. 화염 지팡이/맹독 약병을 구매해 가방에 배치하고 전투를 시작한다. 보관함 아이템은 발동하지 않는다.
4. 상대 상태 아이콘에 커서를 올려 실제 피해와 중첩 감소를 확인한다.
5. 캐릭터 수치를 두 배로 바꿔 다시 Play하면 무기 피해·방어도·지속 피해도 두 배가 되는지 확인한다.

상점에서 아이템이 나오기를 기다리지 않고 상대의 화상·중독을 확인하려면,
Play 전에 Backpack Prototype → Debug Enemy Override에
`Assets/_Project/Data/Enemies/Enemy_PeriodicTest.asset`을 지정한다.
이 시험 적은 HP 90, 기준 공격력 10이며 화염 지팡이와 맹독 약병을 사용한다.
Attack을 바꾸면 해당 적의 무기와 상태 피해가 함께 변한다. 시험 후 Override를 비우면 정상 스테이지 구성으로 돌아간다.
정상 12라운드의 등장 적은 이 시험 적으로 변경하지 않았다.

가시·흡혈 자체와 회복 아이템 효과는 이번 구현 범위가 아니다.
