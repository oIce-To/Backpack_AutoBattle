# 상점 화면 디자인 v2

작성일: 2026-11-13

후속 시안: 사용자가 이 화면 구성을 승인하고 픽셀 아트 표현을 요청했다. 배치를 유지한 스타일 발전안은 [픽셀 UI 스타일 v3](UI_PIXEL_STYLE_V3.md)를 참고한다.

## 이번 요청

- 기능 배치만 보이는 와이어프레임에서 색감·프레임·버튼·아트가 함께 보이는 디자인 시안으로 발전시킨다.
- 현재 게임에서 바뀐 다음 적 정보 노출을 확인하고 반영한다.
- PC 게임의 가로 화면 비율을 유지한다. 대화창이 좁아져도 구성 요소를 세로로 재배치하지 않는다.

## 현재 코드에서 확인한 변경

`Assets/_Project/Scripts/Prototype/PrototypePreparationPanel.cs`:

- 기존 상시 적 요약 패널 대신 `적 정보`와 `전투 시작` 버튼을 생성한다.
- 적 정보 팝업의 논리 크기는 652×454이다.
- 팝업 왼쪽에 적 이름, 일러스트, 현재/최대 체력을 표시한다.
- 오른쪽에 6×6 가방을 표시한다. 아이템은 전투용 읽기 전용 View를 사용하며 쿨타임 애니메이션은 끈다.
- 툴팁 내용은 해당 라운드의 적 스냅샷에서 가져온다.

`BackpackPrototypeCombat.cs`의 `TryOpenEnemyPreview`, `CloseEnemyPreview`, `CanEditLoadout`:

- 준비 상태, 드래그 중이 아님, 유효한 적이 있을 때 연다.
- 열기 전에 기존 툴팁과 배치/합성 표시를 정리한다.
- 팝업이 열린 동안 가방 편집과 전투 시작을 막는다.

`PrototypeMenuPopup.cs`와 `BackpackPrototypeController.Update`:

- 닫기 버튼, 배경 클릭, ESC로 닫는다.

`PrototypeStagePlayModeTests.cs`에는 라운드별 적 HP와 장비 수치 반영, 36칸 표시, 팝업 중 전투 시작 차단을 확인하는 테스트 코드가 있다. 이번 디자인 작업에서 Unity 테스트를 실행한 것은 아니다.

## 화면 기준

- 논리 화면: 1280×720, 16:9. 현재 게임의 Canvas 기준 해상도와 동일하다.
- 원본 렌더링도 정확히 1280×720이다.
- 대화창에서는 화면 전체를 같은 비율로 축소한다. 상점·가방·보관함·버튼의 상대 위치를 유지한다.
- 작은 대화창에서는 글씨도 축소된다. 이는 PC 화면을 보는 미리보기이며 모바일용 UI가 아니다.
- 적 정보 팝업은 같은 화면 안에서 652×454 구도로 열린다.

## 시각 방향

- 짙은 청회색 배경과 절제된 황동 테두리.
- 가방은 가죽색 프레임과 구분되는 6×6 칸, 아이템 점유 형태를 유지한다.
- 전투 시작은 금색으로 강조하고 적 정보는 보조 버튼으로 표현한다.
- 고급 아이템의 색, 할인 가격, 상품 잠금을 구분한다.
- 자유 보관함은 넓은 영역을 유지하고 전투 미참여를 명시한다.
- 게임에 있는 알렌·고블린·기사의 보검 아트를 사용한다. 일반 상점 아이템은 이번 시안용 단순 도형 아이콘이며 최종 아트 에셋이 아니다.

## 현재 게임 동작과 구분되는 디자인 제안

- 오른쪽의 출전 캐릭터 일러스트는 공간 활용을 위한 시각적 제안이다. 기존 준비 화면에 이미 있다는 뜻은 아니다. 미리보기의 디자인 옵션에서 숨길 수 있다.
- 상단 정보 정리, 패널 장식, 아이템 카드/가격 표현은 신규 스타일 제안이다.
- 아이템 상세는 시안에서 클릭으로 열어 검토할 수 있다. 실제 게임의 호버 툴팁을 변경한 것이 아니다.
- 예시 진열·배치·툴팁은 디자인 검토용이다. 훈련용 검 1×3, 단검 1×2, 방패 2×2, 숫돌 1×1과 기본 가격은 현재 데이터에서 확인했다. 전투에 적용되는 최종 계산 수치 전체를 재현한 것은 아니다.
- 새로고침·전투 시작·설정·포기는 이동 위치만 안내한다. 구매/전투/저장 기능을 미리보기에서 실행하지 않는다.

## 검증과 변경 범위

- 미리보기의 스크립트 오류, 아트 로딩, 6×6 칸 수, 팝업 열기/닫기, 배경 입력 차단, 아이템 상세를 브라우저에서 확인했다.
- 대화창 너비 1024, 736, 320에서도 화면의 16:9 비율과 전체 화면 축소가 유지됨을 확인했다.
- 상점·적 정보 팝업·아이템 상세의 1280×720 렌더링을 확인했다.
- 게임 스크립트·씬·데이터·원본 아트는 변경하지 않았다. 사용자가 진행 중인 코드 수정은 그대로 두었다.
