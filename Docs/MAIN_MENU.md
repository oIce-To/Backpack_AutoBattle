# 메인 화면과 스테이지 진입

## 실행

Unity에서 `Assets/Scenes/MainMenu.unity`를 열고 Play를 누른다. 빌드의 첫 씬도 MainMenu다.
메인 하단의 `장비 / 캐릭터 / 메인 / 스테이지` 탭으로 화면을 전환한다. 메인은 중앙에서 현재 선택을 요약하고 출전과 종료를 제공한다. 화면 상단에는 경험치 아이콘과 공유 잔액을 표시하며, 출전하면 탭과 재화 표시를 함께 숨긴다.
캐릭터·스테이지를 미리 본 뒤 선택 버튼으로 확정하고, 메인의 `스테이지 시작`을 누르면 해당 스테이지의 1라운드 상점으로 진입한다. 취소·뒤로 또는 다른 탭으로 이동하면 미확정 미리보기는 저장하지 않는다.
`게임 종료`는 빌드에서 앱을 종료하고 Unity 에디터에서는 Play 모드를 끝낸다.

`Assets/Scenes/Prototype_Backpack.unity`를 직접 열면 개발용으로 기존처럼 상점부터 시작한다. 라운드 건너뛰기와 미완성 아이템은 유지한다.

## 데이터와 화면 흐름

- 이름, 일러스트와 외부 기본 능력치는 `Assets/_Project/Data/Character_Default.asset`의 CharacterData에 저장한다. Portrait에는 사용자가 지정한 `Art/Characters/Allen/allen-standing-approved.png`의 기존 스프라이트를 참조한다. 원본 PNG와 임포트 설정은 변경하지 않는다.
- 메인 화면의 능력치는 CharacterData의 기본 수치, 저장된 레벨, 고유 장비 보너스를 반영한다. 출전할 때 능력치와 시작 장비를 확정하고 스테이지가 끝날 때까지 능력치를 유지한다.
- MainMenu는 진입 씬이다. `PrototypeMainMenuEntry`가 기존 Prototype_Backpack 씬을 불러오면서 메인 화면으로 시작하라는 요청을 한 번 전달한다. 아이템 목록·스테이지·상점 설정을 두 씬에 복제하지 않는다.
- 클리어/게임 오버 화면에서 재시작, 메인 복귀, 전투 통계를 선택할 수 있다. 상점 아래의 `스테이지 포기`를 확정하면 부분 보상 없이 메인으로 돌아간다. 이미 기록한 최고 도달 라운드는 유지된다.
- 메인 복귀 시 전투·통계 화면, 아이템·보관함·상품·잠금·합성 예약·툴팁 등 이전 런의 화면 상태를 정리한다. 메인에서 다시 시작하면 시작 골드·라이프·1라운드·시작 아이템으로 새로운 런을 생성한다. 기존에 전달한 종료 결과 스냅샷은 수정하지 않는다.
- 매 전투는 설정의 기본 배속으로 재생 상태에서 시작한다. 기본값은 1배속이다.
- 상단 톱니바퀴로 소리·화면·전투 설정을 열 수 있다. 전체 볼륨은 배경 음악과 타격음 채널에 공통 적용되며, 클립은 프로토타입 컨트롤러의 Game Audio에서 지정한다.
- 화면 설정은 독립 실행 파일에서 적용된다. 기본 화면은 1280×720 창 모드이며, 지원하지 않는 경우 가까운 해상도를 사용한다. 적용 후 15초 안에 유지하면 저장하고, 되돌리기·Esc·시간 초과 시 직전 화면으로 복구한다.
- 환경설정은 진행도와 별개로 `Application.persistentDataPath/settings.json`에 저장한다. 화면 설정의 기본값 복원도 적용과 확인을 거친다.

## 캐릭터·스테이지 목록

- `Assets/_Project/Data/AdventureCatalog.asset`의 Characters/Stages 목록으로 선택 가능한 원본 SO를 관리한다. 프로토타입 컨트롤러의 Adventure Catalog 필드에 연결한다.
- 알렌은 `Character_Default.asset`, 세레나는 `Character_Serena.asset`이다. 각각 고유한 Character ID(`allen`, `serena`), 이름, Portrait, 체력·공격력을 가진다. 저장에 사용하는 ID는 표시 이름과 분리되어 있으며, 기존 캐릭터의 ID를 바꾸지 않는 것을 권장한다.
- 알렌과 세레나의 기본 체력은 50, 공격력은 10이다. 이번 버전에서는 두 캐릭터를 바로 선택할 수 있다. 처음 획득할 때 알렌에게 일반 +0 기사의 보검, 세레나에게 일반 +0 은빛 장궁을 장착한다.
- 캐릭터 SO의 Passive에 고유 패시브를 지정한다. 알렌의 `굴하지 않는 자`는 라이프 +1과 잃은 라이프에 비례하는 전투 시작 방어도, 세레나의 `궁수의 집중`은 원거리 공격 시도마다 30% 확률의 집중 1중첩을 제공한다. 상세 박스의 장비·패시브 아이콘은 72×72이며 패시브 위에 커서를 올리면 설명을 보여준다. 규칙과 그림 생성 프롬프트는 [캐릭터 패시브](CHARACTER_PASSIVES.md)를 참고한다.
- 승인된 그림은 `Art/Characters/Allen/allen-standing-approved.png`, `Art/Characters/Serena/serena-standing-approved.png`의 기존 스프라이트를 참조한다. 원본 이미지와 임포트 설정을 변경하지 않는다.
- 현재 선택 목록은 1~5스테이지다. 기존 8스테이지 강화 예시 SO와 목록 참조는 삭제했다. 1스테이지 원본을 유지하면서 2~5스테이지의 라운드별 HP·공격력을 단계적으로 높였다. 각 스테이지는 12라운드, 마지막 라운드는 보스 표시, 적 가방은 모두 6×6이다. 미정인 권장 능력치·보상 수치는 추가하지 않았다.
- 처음에는 1스테이지만 도전 가능하며, 바로 이전 스테이지의 마지막 라운드를 승리해야 다음 스테이지가 열린다. Adventure Catalog의 Stages 순서가 진행 순서를 정의한다. 방문하거나 12라운드에 도달하는 것만으로는 해금되지 않는다. 잠긴 선택 박스는 옅은 회색으로 표시하고 클릭을 비활성화하며, 선택·출전 처리에서도 같은 제한을 검사한다.
- 스테이지 선택 화면에는 라운드 수, 실제 라운드 데이터의 주요 적·보스, 해당 스테이지의 클리어 여부·최고 도달 라운드를 표시한다.

## 캐릭터 캐러셀

- 중앙에 현재 미리보는 캐릭터를 크게 표시하고 양옆에 이전·다음 캐릭터를 부분적으로 표시한다. 옆 캐릭터는 전용 UI 셰이더로 채도를 낮추고 옅게 표시한다. 원본 이미지 파일은 수정하지 않는다.
- 마우스 휠 아래/위, 키보드 오른쪽/왼쪽 방향키, 양옆 캐릭터 클릭으로 순환 이동한다. 현재 두 캐릭터만 있으므로 양옆에는 같은 다른 캐릭터가 보인다. 캐릭터가 추가되면 각각의 이전·다음 캐릭터를 표시한다.
- 이동 중에는 현재 위치에서 연속적으로 보간하고, 반대 방향을 입력해도 위치를 즉시 바꾸지 않는다. 화면 밖 슬롯을 재활용하여 순환 경계에서도 이어진다. 전투 배속과 별개의 실제 시간으로 애니메이션을 재생한다.
- 이동이 끝나면 오른쪽 정보 패널의 `선택`을 사용할 수 있다. 이동·미리보기 자체는 저장하지 않으며, 취소하면 이전에 확정한 캐릭터를 유지한다. 캐릭터 탭을 떠나면 해당 키보드·휠 입력은 동작하지 않는다.
- 하단의 캐릭터 번호·총수·조작 안내는 표시하지 않는다. 오른쪽 정보 패널을 아래로 확장하고, 연한 초록색 선택 버튼은 취소 버튼과 같은 크기·높이에 둔다.

## 고유 장비

- 장비 탭에서 아이콘을 누르면 상세 팝업이 열린다. 팝업 왼쪽 아래에서 `장착` 또는 `장착 해제`를 선택한다. 팝업 밖을 누르면 닫힌다. 새 장비를 장착하면 같은 슬롯의 기존 장비는 공용 보관함으로 돌아간다. 다른 캐릭터가 장착 중인 장비는 확인 팝업에서 `예`를 눌러 옮긴다. 빈 슬롯으로도 출전할 수 있다.
- 장비 아이콘에는 등급 색상의 얇은 테두리를 표시한다. 능력치 보너스는 `장착한 캐릭터의 체력 +5%`처럼 적용 대상을 명시한다. 제작 팝업 하단 왼쪽에는 필요한 재료 아이콘과 수량을, 오른쪽에는 제작 버튼을 표시한다.
- 제작 목록 카드에는 등급 테두리를 표시하지 않는다. `무기 / 방어구 / 장신구·펫` 탭으로 제작할 슬롯을 고른다. 제작 성공 후에도 같은 제작 팝업을 유지하며, 갱신된 보유 재료로 다시 제작할 수 있는지 판단한다.
- 보유 장비는 `전체 / 무기 / 방어구 / 장신구·펫` 순서의 탭으로 분류한다. 기본은 전체이며, 제작 목록과 별개로 분류를 유지한다. 분류를 바꿔도 잠금 모드는 유지되며 분해 창에서는 모든 보유 장비를 확인할 수 있다.
- Adventure Catalog의 Unique Gear 목록에 장비 정의를 등록한다. 정의의 Item에는 Unique Gear로 표시한 ItemData를 연결한다. 무기·방어구·장신구/펫 슬롯은 ItemData의 종류를 확인한다.
- 일반 장비는 +0~+3에서 5~6.5%, 고급 장비는 +0~+6에서 6.5~9.5%를 부여한다. 능력치별 장비 보너스를 합산해 레벨이 반영된 수치에 곱한다. 장비의 전투 고유 효과는 등급에 따라 정해지며, 가방 안에서만 작동한다.
- 출전 시 복사된 장비는 가방과 보관함 사이에서 옮기고 회전할 수 있다. 스테이지 상점 판매와 합성은 할 수 없다.
- 장비 탭의 `장비 제작`에서 기원의 파편 500개와 해당 설계도 10개로 일반 +0 장비를 만든다. 장비 상세 팝업에서 강화와 승급을 진행한다.
- 일반 강화 비용은 500 / 700 / 1000개, 고급 강화 비용은 2000 / 2500 / 3200 / 4000 / 5000 / 6500개다. 강화 버튼에 파편 아이콘과 비용을 표시하며, 강화할 수 없으면 버튼을 어둡게 표시한다.
- 일반 +3 장비에 동일한 일반 +0 미장착 장비 두 개를 소모하면 같은 인스턴스가 고급 +0으로 승급한다. 승급 창에서 사용할 재료 두 개를 직접 선택하고 확정한다. 가능한 재료를 먼저 정렬하고 나머지는 회색으로 표시한다. 장착 상태는 이어진다.
- 승급 가능한 등급의 최대 강화 장비는 재료가 없어도 승급 창을 열 수 있다. 실제 승급 확정은 적합한 재료 두 개를 선택해야 가능하다.
- 보유 장비 목록 아래의 `분해`로 여러 장비를 선택할 수 있다. 미장착·잠금 해제 장비를 먼저 정렬하며, 모든 캐릭터의 장착 장비와 잠긴 장비는 아래에 어둡게 표시한다. 선택한 장비의 반환 파편과 장비별 설계도를 확인하고 `분해`를 확정한다.
- 분해는 제작·강화·승급 재료까지 포함한 파편 비용의 50%, 설계도 비용의 80%를 반환한다. 등급·강화별 반환량은 한 번 생성한 표에서 조회하며 실제 지출 이력은 필요하지 않다. 일반 +2는 파편 850개·설계도 8개, 고급 +0은 파편 1,850개·설계도 24개다. 장비 삭제와 보상 지급은 하나의 저장으로 처리한다.
- 분해 버튼 오른쪽의 `장비 잠금 모드`에서는 목록 또는 장착 슬롯을 좌클릭해 잠금/해제를 전환한다. 다시 버튼을 누르면 상세 팝업을 여는 기본 모드로 돌아온다. 잠긴 장비는 아이콘 왼쪽 위와 상세 창의 이름 옆에 노란 자물쇠로 표시한다. 분해와 승급 재료로는 사용할 수 없으며, 장착·이동·강화·중심 장비의 승급은 가능하다. 설계도 교환은 추후 구현한다.

## 기원의 광산과 재화

- 상단 경험치와 기원의 파편 패널은 금액과 상관없이 같은 고정 크기다. 보유량·강화/레벨업 비용·예상 보상은 K/M/B와 소수점 한 자리로 축약한다. 상단 재화에 마우스를 올리면 이름과 정확한 보유량을 보여준다. 저장 및 구매 가능 여부는 축약 전 정수 수치로 계산한다.
- 스테이지 탭의 `일반 스테이지 / 기원의 광산`으로 종류를 고른다. 광산 1~5는 각각 일반 1~5의 12라운드 구성을 복사한 독립 SO이며, 직전 광산을 클리어해야 다음 광산이 열린다.
- 티켓은 최초 5장, 최대 5장이다. 한 장에 8시간이 걸리며 종료 중에도 UTC 시각으로 충전한다. 보유량이 가득 차면 충전이 멈추고, 그때 한 장을 쓰면 새 8시간이 시작된다.
- 에디터의 `Tools > Backpack AutoBattle > Refill Mine Tickets`는 티켓을 즉시 5장으로 충전한다. 정지 상태에서는 저장 파일을, 실행 중에는 메인 화면에 진입해 불러온 진행도를 갱신한다. 다른 재화와 진행 기록은 유지한다.
- 광산은 티켓이 있어야 출전할 수 있고, 최종 클리어 보상 저장과 티켓 한 장 차감을 함께 처리한다. 패배와 포기는 티켓을 소모하지 않는다. 클리어한 광산의 `소탕`은 같은 보상을 즉시 지급한다.
- 일반 클리어 파편은 100 / 126 / 159 / 200 / 252개다. 패배 시 경험치와 같은 10% / 25% / 50% 비율을 적용하고 소수 수량은 버린다.
- 광산 클리어 파편은 500 / 630 / 794 / 1000 / 1260개, 설계도는 5 / 6 / 7 / 8 / 9개다. 각 설계도는 등록된 고유 장비 중 같은 확률로 한 장씩 추첨하며 광산 경험치는 0이다.

## 최소 진행도 저장

- 저장 파일은 `Application.persistentDataPath/player-progress.json`이다. 프로젝트의 SO나 Art 파일에 진행도를 쓰지 않는다.
- 마지막으로 확정한 캐릭터 ID·스테이지 ID와 스테이지별 클리어 여부·최고 도달 라운드를 저장한다. 스테이지 기록은 캐릭터 간 공유하며, 캐릭터별 최고 기록은 이번 범위에 포함하지 않는다.
- 메인에서 시작한 런은 스테이지 진입·라운드 이동·최종 클리어 시 기록을 갱신한다. 같은 라운드에서 재패배하거나 낮은 라운드에 재도전해도 최고 기록·클리어 여부가 감소하지 않는다. 클리어 판정은 마지막 라운드 승리일 때만 기록한다.
- 종료 후 다시 실행해도 선택과 진행도는 유지한다. 진행 중인 런의 이어하기는 지원하지 않는다. 새 도전은 항상 1라운드·시작 골드·시작 라이프·시작 가방 구성으로 시작한다.
- 개발용 라운드 건너뛰기는 유지하며, 메인에서 시작한 런에서 건너뛰어 도달한 라운드도 기록한다. Prototype_Backpack 씬을 직접 열어 시작한 개발용 런은 기록을 저장하지 않는다. 이후 메인으로 돌아와 새 런을 시작하면 저장 대상이 된다.
- 저장 버전 4는 파편, 장비별 설계도, 티켓과 충전 시각을 추가한다. 이전 진행도와 장비를 유지하며 처음 티켓 5장을 적용한다. 임시 파일을 통한 교체와 직전 파일 백업(`.bak`)을 사용한다. 읽기 실패 시 유효한 백업을 복구하며, 백업도 읽을 수 없거나 저장이 더 최신 버전이면 기존 파일을 보존하고 메인에 안내한다.
- 저장 버전 5는 장비별 잠금을 추가한다. 기존 버전 1~4의 장비는 잠금 해제 상태로 가져오고 장비·재화·진행도는 유지한다.
- 선택한 콘텐츠가 목록에서 빠지면 현재 기본 캐릭터·스테이지로 시작할 수 있게 한다. 목록에 없는 스테이지의 과거 기록은 파일에서 지우지 않는다.
- 따라서 예전 저장 파일의 8스테이지 선택은 현재 기본 스테이지로 돌아가며, 과거 8스테이지 기록을 5스테이지 클리어 기록으로 임의 변환하지 않는다.
- 저장된 선택이 아직 잠긴 스테이지라면 첫 도전 가능 스테이지로 돌아간다. 기존 기록이 있다는 이유만으로 해금하지 않는다.
- 2026-11-03 요청에 따라 로컬 개발 진행 기록을 한 번 초기화했다. 선택 캐릭터는 유지하고, 선택 스테이지는 1스테이지·도전/클리어 기록은 없는 상태로 바꿨다. 복구용 `.bak`도 초기화하여 이전 기록이 복원되지 않도록 했으며, 초기화 전 파일은 QA 폴더에 별도로 보관했다. 매 실행마다 초기화하는 코드는 추가하지 않았다.
- 자동 테스트는 `BACKPACK_PROFILE_PATH`로 지정한 별도 파일을 사용한다. 정상 실행에서는 별도 환경 변수 없이 앱의 저장 경로를 사용한다.

공유 경험치 보상과 캐릭터별 레벨업은 [경험치와 레벨](EXPERIENCE_AND_LEVELS.md)을 참고한다. 캐릭터 탭에서 미리보는 캐릭터에 투자하며, 출전 선택은 따로 확정한다. 전투 화면에는 선택한 캐릭터와 적 데이터에 지정한 일러스트가 표시된다.
