# 전투 화면 픽셀 UI

2026-11-16 확인 완료

## 화면

- 양쪽 가방: 상점/적 정보와 같은 갈색 가죽, 손잡이, 바느질, 버클 프레임과 빈 칸. 기존 228×228 크기를 유지하며 양쪽 바깥으로 이동.
- 캐릭터: 가방 안쪽에 나란히 배치하고 일러스트 영역을 224×200에서 224×350으로 확대. 이름은 일러스트 위, 체력은 아래에 배치하며 일러스트 외곽 테두리는 두지 않는다.
- 일시정지·배속: 갈색 나무 판자, 픽셀 나뭇결과 작은 고정쇠. 선택 상태는 밝은 목재색으로 구분. 전투 통계·상점 복귀는 기존 공통 픽셀 버튼 유지.
- 통계 창: 공통 패널과 버튼, 선택 탭 강조. 통계 계산과 조작은 유지.
- 체력바: 244×36 외곽 안에 좌우 8px/상하 6px 여백과 마스크를 두어 채움과 숫자가 테두리를 침범하지 않게 제한. 숫자는 안쪽 영역에 맞춰 크기를 조정하며 채움 비율은 0~1로 제한한다. 0 HP에서는 채움 너비도 0.
- 방어도: 기존 하늘색을 유지한 단순한 방패. 2px 단위 계단형 실루엣으로 다시 그렸으며 체력바 왼쪽에 겹치지 않게 배치. 0 방어도는 숨긴다.
- 상태 아이콘: 각 아이콘의 개별 테두리를 제거하고 양쪽에 긴 세로 프레임 하나씩 사용한다. 간격은 12px에서 6px로 줄였다. 기존 형태/색상 구분과 밝은 라벤더색 실명, 중첩 수·툴팁·스크롤은 유지.

## 피해와 회복 숫자

기존 피해 숫자 아틀라스, 흰색 일반 피해, 금색 치명타, 상태 피해 색상을 유지한다.

- 일반 피해/회복: 약 0.95초 동안 위로 상승하고 좌우로 조금 흩어지며 후반부에 페이드아웃.
- 치명타: 약 1.1초 동안 더 높이 상승. 초반에 최대 22% 커졌다가 원래 크기로 돌아오며 작은 회전을 추가.
- 가로 이동과 확대·회전 여유를 포함해 캐릭터별 피해 표시 영역 안에서 시작 위치를 선택한다.
- `Heal` 아이템 이벤트와 흡혈 반응의 **실제 회복량**을 초록색 `+숫자`로 표시한다. 회복량이 0이면 생성하지 않는다. 기존에는 해당 회복이 로그에만 표시됐다.
- 플러스는 기존 아틀라스의 빼기 기호를 조합해 그린다. 원본 폰트 이미지나 피해 숫자 디자인은 교체하지 않았다.
- 전투 배속과 무관한 실제 시간으로 재생한다. 일시정지 중에도 이미 생성된 숫자는 애니메이션을 마친다. 피해 숫자 숨김 설정은 회복 숫자에도 적용된다.
- 한쪽당 8개 풀을 재사용한다. 새 전투/화면 초기화 시 기존 정리 동작을 유지한다.

## 확인 방법

`Assets/Scenes/Prototype_Backpack.unity`를 열고 Game 뷰를 16:9로 맞춘 뒤 Play → 전투 시작.
실명/버프·디버프는 해당 효과가 적용됐을 때 표시되며, 회복 숫자는 실제 회복 이벤트가 발생해야 나타난다.

`PrototypeBattlePresentationTests`는 광폭화 시점까지 전투를 진행하고 모든 종류의 상태를 양쪽에 나눠 표시한다. 별도의 UI 이벤트로 치명타·회복 숫자의 상승, 확대, 페이드, 소멸 및 0 회복 생략을 검증한다. 실제 흡혈 이벤트의 초록색 회복 숫자는 `PrototypeDamageReactionTests`로 검증한다.

최신 배치의 검증/캡처는 `Logs/BattleLayoutV2`에 저장하며 별도 `BACKPACK_PROFILE_PATH` / `BACKPACK_SETTINGS_PATH`를 사용한다. `BattleMotion-*.png`는 테스트 장면에서 실제 Unity 숫자 애니메이션을 시간 순서로 렌더링한 프레임이다.

PlayMode 전체 실행은 114개 중 112개 통과(`tests.xml`). 이전 회피율 위치와 계층 순서를 가정한 두 검증을 새 배치 및 화면상 아이콘 순서에 맞춰 수정한 뒤, 해당 두 클래스의 5개 테스트가 모두 통과했다(`recheck.xml`). 테스트별 최신 결과는 **114/114 통과**이며, 단일 전체 재실행 결과와는 구분한다. 체력 0/절반/최대/초과 시 채움 너비 및 마스크, 가방 크기 유지, 방패 픽셀 좌표, 상태 간격과 기존 전투 동작을 확인했다.

`BattlePixelCriticalAndHeal.png`에서 모든 상태 종류와 새 배치를, `Playback3x.png`에서 목재 배속 버튼의 선택 상태를, `ArmorBadgePreview.png`에서 양쪽 픽셀 방패를 확인할 수 있다. 해당 장면의 치명타/회복 이벤트와 방어도 미리보기 값은 UI 검증용이며, 일반 게임에서는 실제 전투 상태에 반응한다. 이전 버전의 113개 전체 통과 기록과 애니메이션 GIF는 `Logs/BattlePixelUI`에 남아 있다.
