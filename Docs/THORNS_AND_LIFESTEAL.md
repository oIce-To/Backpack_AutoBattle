# 가시와 흡혈

## 규칙

- 가시: 공격 아이템의 피해를 받으면 공격자에게 `가시 보유자의 스테이지 진입 공격력 × 0.10 × 중첩` 피해를 반사한다.
- 흡혈: 공격 아이템으로 피해를 주면 `흡혈 보유자의 스테이지 진입 공격력 × 0.10 × 중첩` 체력을 회복한다. 공격 피해량에 비례하는 흡혈률이 아니다.
- 기준 공격력 10, 3중첩이면 각각 반사 피해 3 / 회복량 3이다. 기준 공격력 20이면 각각 6이다.
- 방어도로 전부 막힌 공격도 둘 다 발동한다. 명중 실패·회피 또는 실제 피해/방어도 흡수가 모두 0인 공격은 발동하지 않는다.
- 반사 피해는 방어도를 먼저 소모하며, 명중·회피·치명타 판정을 하지 않는다.
- 화상·중독·가시 반사·기타 비공격 피해는 가시/흡혈을 발동하지 않는다. 반사가 서로 무한 반복되지 않는다.
- 중첩 상한이나 자동 감소는 없다. 아이템 속도와 무관한 공격 결과 반응이므로 신속/빙결이 반사·회복량을 바꾸지 않는다.
- 체력 회복은 최대 체력을 넘지 않는다. 사망한 대상을 되살리지 않는다.

하나의 공격을 `공격 피해 → 해당 무기의 명중 연계 효과 → 공격자 흡혈 → 방어자 가시 → 승패 판정` 순서로 끝까지 처리한다.
가시 보유자가 마무리 공격으로 사망하더라도 그 공격에 대한 가시는 반사한다.
그 결과 양쪽 체력이 모두 0이면 **그 마무리 공격을 한 쪽**이 이긴다. 플레이어 공격이면 승리, 적 공격이면 패배이다.
방어자가 살아 있고 공격자만 반사로 사망하면 방어자가 이긴다.

## 데이터와 확장

- `StatusEffectKind` 끝에 Thorns / Lifesteal을 추가해 기존 SO의 상태 종류 번호를 유지했다.
- `Status_Thorns`, `Status_Lifesteal` SO의 Amount Scaling은 Attack / 0.1이다. SO는 전투 시작 때 복사하며 외부 능력치도 스테이지 진입 스냅샷을 쓴다.
- 기존 `_damageScaling` 직렬화 이름은 유지하여 화상/중독 SO와 호환된다. Inspector 표시 이름만 Amount Scaling으로 공통화했다.
- `CombatDamageReactionRule`은 공격자가 피해를 줬을 때 / 방어자가 피해를 받았을 때의 공통 반응 조건을 구분한다.
- `CombatReactionEvent`는 요청 회복량과 실제 회복량, 반사 피해의 방어도/HP 흡수 결과, 원인이 된 공격 아이템 ID를 제공한다.
- 반사 경로는 `CombatDamageKind.Other`를 쓰며 공격 결과 반응을 재귀 호출하지 않는다. 외부 `DamageApplied` 구독에 기대지 않아 승패를 너무 일찍 확정하지 않는다.
- 화면은 상태 아이콘/중첩, 최종 수치만 보여주는 짧은 툴팁, 회복/반사 피드백과 전투 로그를 갱신한다. 이미 최대 체력이면 `+0` 피드백은 띄우지 않는다.
- 가시 아이콘은 회색 가시공, 흡혈 아이콘은 긴 위쪽 송곳니와 위아래 치열이 보이는 빨간 입 모양이다. 배경과 입 안쪽은 투명하다. 실명 아이콘은 기존 문양을 유지하되 검은색으로 구분한다.

## 테스트용 콘텐츠

두 아이템의 가격/크기/중첩은 시스템 확인용 임시 밸런스이다.

| 아이템 | 등급 / 가격 | 크기 | 효과 |
| --- | --- | --- | --- |
| 가시 갑옷 | 희귀 / 5G | 2×2 | 전투 시작 시 자신에게 가시 3 |
| 흡혈의 부적 | 희귀 / 5G | 1×1 | 전투 시작 시 자신에게 흡혈 3 |

상점 카탈로그에 포함된다. 보관함에서는 발동하지 않고 가방에 배치한 개수만큼 전투 시작 시 중첩을 부여한다. 자체 사용 주기는 없다.

1. Play 전에 씬의 Backpack Prototype → Debug Enemy Override에 `Enemy_ReactionTest`를 지정한다.
2. 이 적은 HP 120, 기준 공격력 10, 6×6 가방에 고블린 몽둥이·가시 갑옷·흡혈의 부적을 가진다.
3. 전투에서 적의 가시/흡혈 3중첩 아이콘과 툴팁의 반사 3 / 회복 3을 확인한다. 피격 후 적이 공격하면 흡혈 회복이 보인다.
4. 플레이어도 테스트 아이템을 구매해 가방에 넣어 양쪽 동작을 확인할 수 있다.
5. 시험 후 Debug Enemy Override를 비우면 정상 라운드 구성으로 돌아간다. 기존 12라운드에는 이 시험 적을 자동 배정하지 않았다.

회복 물약 등 별도의 아이템 회복 효과는 이번 범위에 포함하지 않는다.
