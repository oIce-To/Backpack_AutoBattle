# 아이템별 전투 통계

## 확인 방법

전투가 끝나면 전투 화면의 `전투 통계` 버튼으로 기록을 연다. 라이프 소진 게임 오버와 최종 클리어 화면에도 별도의 `전투 통계` 버튼이 있어 마지막 전투를 확인할 수 있다.
플레이어/적 탭으로 양쪽 기록을 전환한다. 그 아래 검/방패 아이콘으로 공격/방어 통계를 선택한다. 목록이 길면 마우스 휠로 스크롤한다. 닫기는 기존 승패/런 결과 화면으로 돌아갈 뿐, 라운드 진행이나 재시작을 실행하지 않는다.
각 항목은 같은 종류끼리 합치지 않고 아이템 인스턴스 단위로 표시한다. 아이템 이름만 표시하며 위치 좌표와 하단의 작은 안내문은 표시하지 않는다. 보관함 아이템은 전투에 참여하지 않아 목록에 없다.

## 막대그래프와 툴팁

- 공격은 실제 피해 총량, 방어는 `실제 회복 + 방어도 흡수 + 실제 피해 감소량`의 합산값으로 내림차순 정렬한다. 내부 원본 값으로 정렬하며 동률이면 인스턴스 ID 순서를 사용한다.
- 선택한 진영/분류에서 가장 높은 항목의 막대가 최대 길이다. 나머지는 그 항목 대비 비율로 표시한다. 0인 항목은 목록에는 남기되 색상 구간을 만들지 않는다.
- 직접 공격 피해는 흰색, 화상은 빨간색, 중독은 보라색, 가시는 회색으로 표시한다. 상태 피해 색상은 해당 상태 아이콘과 같은 색상 정의를 사용한다. 분류되지 않은 기타 피해는 중립 회색으로 표시한다.
- 방어 그래프의 회복은 연두색, 방어도 흡수는 하늘색, 실제 피해 감소량은 흰색이다.
- 막대에 커서를 올리면 해당 항목에 포함된 종류별 수치와 합계를 작은 툴팁으로 표시한다. 목록 스크롤/진영·분류 전환/닫기 때 툴팁을 숨긴다. 툴팁은 화면 밖으로 나가지 않도록 위치를 제한한다.
- 합계는 `공격 / 방어`로 표시하며 회복과 방어도 흡수를 따로 나열하지 않는다.

## 집계 기준

| 항목 | 기록 기준 |
| --- | --- |
| 입힌 피해 | 실제 체력 피해 + 실제 방어도 흡수량. 남은 체력을 넘긴 초과 타격은 제외 |
| 방어 중 체력 회복 | 실제로 회복된 HP만 기록. 최대 체력을 넘긴 초과 회복 제외 |
| 방어 중 방어도 흡수 | 그 아이템이 만든 방어도로 실제 흡수한 피해만 기록. 생성 후 남은 방어도는 제외 |
| 방어 중 피해 감소 | 실제 감소한 피해만 기록할 수 있는 별도 항목. 피해 감소 아이템 효과 자체는 아직 추가하지 않음 |

화상/중독 피해는 상태를 부여한 아이템, 흡혈/가시의 회복·반사 피해는 해당 버프를 부여한 아이템에 귀속한다. 흡혈을 발동시킨 공격 무기에 회복량을 중복 기록하지 않는다.
여러 아이템이 같은 상태를 부여했으면 현재 남아 있는 기여 중첩 비율로 실제 성과를 분배한다. 예를 들어 흡혈 1/3중첩을 준 두 아이템이 있고 실제 회복이 1이면 각각 0.25/0.75다.
신속·정밀·숫돌 등 다른 아이템을 강화한 간접 기여는 별도의 가상 피해/회복/방어로 추정하지 않는다. 해당 아이템은 직접 기록이 없으면 0으로 표시한다. 무기의 강화된 실제 피해는 그 무기의 피해에 포함된다.
현재 실제 회복 효과인 흡혈을 기록하며, 미완성 회복 물약의 효과를 새로 구현하지는 않았다.

## 방어도 비율 분배

방어도는 하나의 공용 수치로 유지하되, 출처별 잔여량을 따로 기록한다. **피해가 흡수될 때마다** 직전 잔여량 비율로 방어 성과를 분배하고 같은 비율로 출처별 잔여량을 소모한다.

- A 50 + B 40이 함께 남은 상태에서 60 흡수: A 33.333… / B 26.666… 기록. 남은 공용 방어도는 30.
- A 50 생성 → 30 흡수 → B 40 생성 → 30 추가 흡수: 최종 A 40 / B 20 기록. 나중에 생성된 B가 앞선 피해의 성과를 가져가지 않는다.
- 일반 공격뿐 아니라 화상·중독·가시 등으로 방어도가 소모된 경우에도 실제 흡수량을 기록한다.

내부 값은 반올림하지 않는다. 각 분배의 마지막 출처에 부동소수점 잔차를 정산해 총 기록이 실제 흡수량과 맞도록 한다. 화면과 툴팁에서만 소수점 한 자리까지 표시한다(33.333… → 33.3, 26.666… → 26.7). 여러 행의 표시값을 직접 더하면 합계와 작은 반올림 차이가 있을 수 있다.

## 전투 결과를 바꾸지 않는 출처 추적

지속 피해는 기존처럼 부여자 진영별로 합쳐 계산한다. 같은 편의 아이템이 둘이라고 물리적인 지속 피해 이벤트를 둘로 나누지 않는다. 실제 피해를 계산한 뒤 그 결과를 출처별 중첩 비율로 분배하므로 처치 시점, 초과 피해, 이벤트/상태 감소 순서가 통계 때문에 바뀌지 않는다.
화상의 자연 감소/상태 제거는 기존 부여자 처리 순서를 유지하고, 해당 부여자 안에서 먼저 등록된 아이템 출처부터 제거한다. 남은 중첩의 출처를 다음 통계 계산에 사용한다.
아이템 없이 코드로 직접 부여한 효과는 원인을 임의로 추정하지 않고 해당 진영의 `기타 효과`에 기록한다.

## 데이터와 수명

- `CombatStatistics.cs`: 출처별 누적, 방어도/상태 기여 추적 및 불변 통계 스냅샷.
- `CombatSimulation.CaptureStatistics()`: 현재 기록의 분리된 읽기 전용 복사본을 반환한다. 여러 번 읽어도 중복 집계하지 않는다.
- `CombatItemStatistics`: 진영과 인스턴스 ID, 이름/내부 위치 메타데이터, 실제 HP/방어도 피해, 회복, 방어량을 제공한다. 직접 공격/화상/중독/가시/기타 피해와 실제 피해 감소량을 따로 보관해 그래프와 툴팁에 사용한다. 위치 메타데이터는 UI에 노출하지 않는다.
- `CombatStatisticsChart`: 내부 정밀도를 유지하는 정렬/합산/구간 분류와 표시용 한 자리 반올림을 담당한다.
- `RecordDamageReduction(source, sourceItemId, preventedDamage)`: 향후 피해 계산기가 실제로 줄인 피해를 보고하는 통계 연결점이다. 이 API 자체는 피해를 줄이거나 새 아이템 효과를 실행하지 않는다. 현재 일반 플레이에서 실제 감소 효과를 새로 부여한 것은 아니다.
- `ApplyStatus`의 마지막 선택 인자 `sourceItemId`는 해당 상태를 부여한 아이템 인스턴스를 지정한다. 실제 아이템 효과와 전투 시작 부여는 자동으로 전달한다.
- `ApplyNonAttackDamage`의 선택 인자 `sourceItemId`는 명시적인 비공격 피해 출처를 지정할 수 있다.
- 새 전투는 항상 새 누적기를 사용한다. 다음 라운드/재도전/런 재시작에서 기존 기록이 섞이지 않는다. 이번 UI는 직전 종료 전투의 기록만 제공하며 과거 라운드 기록 보관함은 추가하지 않았다.

광폭화로 증가한 실제 피해도 원래 피해를 발생시킨 아이템과 피해 종류에 귀속한다. 90초 강제 패배는 가짜 피해를 추가하지 않으며 전투 시간은 90초로 기록한다. 상세 시간 규칙은 [런 생명주기](RUN_LIFECYCLE.md)를 참고한다. 배속은 후속 작업이다.
