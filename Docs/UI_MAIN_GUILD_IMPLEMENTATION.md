# 길드 메인 UI

2026-11-16

## 적용 범위

- 메인 탭: 화려한 첫 배경과 허름한 두 번째 배경의 중간인, 오래됐지만 잘 관리된 작은 마을 길드. 온전한 회벽, 나뭇결이 살아 있는 목재, 소박한 철제 등불, 정돈된 서가와 접수대, 단순한 붉은 러그를 표현했다. 금장 깃발·웅장한 아치와 심한 균열·누더기는 사용하지 않는다. 캐릭터는 배경과 분리된 기존 실시간 UI 이미지로 유지한다.
- 왼쪽: 양피지 패널에 플레이어명과 캐릭터 정보를 표시한다. 플레이어명 패널은 270×100 → 244×68, 캐릭터 정보 패널은 270×218 → 244×166으로 축소했다. 레벨은 19 → 23으로 확대하며 긴 숫자에 한해 최소 20까지 맞춘다. 이름·체력·공격력의 글자 크기는 유지한다.
- 오른쪽: 철제 모서리와 사각 리벳이 있는 목재 보관소. **HomeBackpackIcon / HomeMailboxIcon 리소스, 아이콘 크기, 클릭 동작은 유지**한다.
- 가방·우편함 팝업: 메인 전용 목재 외곽과 어두운 내부. 설계도 목록·수량·툴팁·닫기 동작은 유지한다.
- 공통 메인 내비게이션: 철제 재화 패널과 목재 탭. 선택한 탭은 밝은 황동색으로 구분한다. 기존 재화 아이콘과 설정 톱니바퀴는 유지한다.
- 캐릭터·장비 탭은 길드 배경을 어둡게 표시하며, 스테이지 탭은 던전/기원의 광산 일러스트를 사용한다. 세 탭의 패널·버튼과 장비 하위 팝업은 메인 전용 스타일을 공유한다. 자세한 내용은 `Docs/UI_GUILD_TABS_IMPLEMENTATION.md` 참조.
- 요청에 따라 길드 제목과 제목 패널, 새 모험/스테이지 선택 안내, 모험가 등록증·출전 모험가·길드 보관소 소제목을 제거했다. 가방·우편함을 감싸는 패널과 아이콘은 유지한다.

## 구현

`PrototypeGuildStyle`은 인스테이지의 `PrototypePixelSkin`과 분리된 전용 스프라이트를 생성한다. 직각 철제 이음새와 사각 리벳, 양피지 테두리를 사용하며 Point 필터와 9-slice로 모서리 도트를 유지한다. 버튼은 Unity의 기본 hover/pressed/disabled 피드백을 사용한다.

`PrototypeGuildHall`은 `Assets/_Project/Resources/UI/GuildHallIllustrated.png`를 읽어 표시한다. Point 필터, 비압축, 밉맵 없음으로 가져오며 비율을 유지한 채 패널을 채우고 넘는 가장자리만 마스킹한다. 배경은 raycast를 받지 않으며 화면 기준 크기는 1280×720이다. 이전 도형 배경은 새 일러스트로 교체했다.

배경은 내장 `image_gen`으로 생성·수정했으며 최종 프롬프트는 `Docs/UI_GUILD_BALANCED_PROMPT.md`, 이전 버전 기록은 `Docs/UI_GUILD_BACKGROUND_PROMPT.md`에 기록했다. 아이콘 리소스는 교체하지 않았다.

## 확인

`Assets/Scenes/MainMenu.unity`에서 Play 후 Game 뷰를 16:9로 확인한다. 메인 탭, 가방·우편함 열기와 닫기, 하단 탭 전환, 상단 설정 진입을 확인한다.

최신 배경 교체의 메인 진입 검증과 실제 Unity 캡처는 `Logs/GuildBalancedUI`에 저장한다. 메인 진입 테스트 **1/1 통과** (`tests.xml`), `MainMenuAllen.png`에서 배경과 기존 UI 배치를 확인했다. 이번에는 이미지와 기록만 변경했으며 UI 코드는 변경하지 않았다. 테스트에서는 별도 `BACKPACK_PROFILE_PATH`와 `BACKPACK_SETTINGS_PATH`를 사용해 플레이 저장 파일과 분리한다.

이전 UI 변경 시 관련 PlayMode **31/31 통과** (`Logs/GuildHumbleUI/tests.xml`). 메인 진입·새 여정·결과 복귀, 탭 이동, 가방/우편함 팝업, 재화·선택·성장, 설정을 기존 테스트로 확인했다. 메인 진입 테스트는 배경 스프라이트 로딩과 Point 필터도 확인한다. 원본 가방/우편함 스프라이트와 클릭 대상, 텍스트 높이 검증도 통과했다.

확인한 1280×720 실제 캡처: `MainMenuAllen.png`, `MainMenuSerena.png`, `MainBlueprintInventory.png`, `MainMailbox.png`.
