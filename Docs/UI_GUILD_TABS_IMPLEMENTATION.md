# 캐릭터·장비·스테이지 탭 UI

2026-11-16

- 캐릭터 탭: 메인 길드 일러스트에 74% 검정 오버레이. 캐릭터 일러스트 영역에는 짙은 철제 패널을 깔아 중앙과 양옆 캐릭터 뒤의 배경을 정돈한다. 이름·레벨·체력·공격력 뒤의 양피지는 제거하고 기존 위치에 밝은 크림색 글자로 표시한다. 장비·패시브는 철제 슬롯, 외곽은 목재 패널. 레벨 업과 선택 버튼은 밝은 목재색.
- 장비 탭: 같은 길드 배경에 78% 검정 오버레이. 장착 캐릭터 정보는 양피지, 보유/제작 목록은 목재 외곽과 불투명한 철제 내부. 분류·잠금 모드 선택은 밝은 목재색. 등급 테두리와 잠금·장착 표시는 유지.
- 장비 하위 흐름: 장착·해제·제작·강화·승급 버튼, 장비 이전 확인, 승급 재료·분해 패널에 같은 스타일을 적용했다. 비용 부족, 잠금 장비, 사용할 수 없는 재료의 기존 비활성화 동작은 유지한다.
- 아이템 상세 툴팁 본문은 인스테이지와 동일한 `PrototypeItemTooltip` 기본 디자인을 사용한다. 장비 탭 전용 철제 배경 덮어쓰기를 제거해 공통 배경과 등급 테두리를 그대로 표시한다.
- 스테이지 탭: `DungeonSelection.png`와 `OriginMineSelection.png`를 일반/광산 카테고리에 따라 교체한다. 64% 검정 오버레이를 유지하고 주요 정보는 불투명한 철제 패널 위에 표시한다. 선택 목록·카테고리·입장·소탕·뒤로 버튼은 메인 탭의 목재 스타일을 공유한다.
- 배경은 클릭을 가로채지 않으며 원본 비율을 유지해 패널을 채운다. 핵심 정보·문구·조작 흐름·기존 게임 계산은 유지한다. 스테이지 분류 버튼 높이와 정보 패널의 하단 여백은 글자와 안내 메시지가 테두리에 닿지 않도록 조정했다.
- 잠긴 스테이지는 불투명한 철제 패널과 회색 글자로 표시한다. 패널 전체를 투명하게 하지 않아 그림이 글자 뒤로 비치지 않는다. 비활성 소탕 버튼도 같은 이유로 불투명하게 유지한다. 비활성 레벨 업 버튼은 밝은 글자로 비용을 읽을 수 있게 한다.

## 구현

`PrototypeGuildHall.Add`를 배경 리소스·어둡기·오브젝트 이름을 지정할 수 있도록 확장했다. 메인 탭은 기존 기본값을 사용한다. `SetIllustration`은 스테이지 배경과 종횡비를 함께 교체한다.

`SelectionUi.GuildButton`은 기존 버튼 생성과 클릭 연결 후 `PrototypeGuildStyle`을 적용한다. 모든 `SelectionUi.Button`을 전역 변경하지 않고 이번 세 탭과 관련 장비 팝업에서만 사용한다. 선택 상태 변경 시에도 스타일을 다시 적용하므로 이전 평면 색상이 새 목재 스프라이트를 어둡게 덮지 않는다.

아직 열리지 않은 팝업의 버튼은 Awake 실행 전에도 사용할 수 있도록 생성 시 `targetGraphic`을 명시적으로 연결한다.

새 배경 두 개는 내장 `image_gen`으로 제작했다. 원본은 프로젝트 Resources에 복사했고 Point 필터·비압축·밉맵 없음 설정을 사용한다. 프롬프트는 `Docs/UI_STAGE_BACKGROUND_PROMPTS.md`에 기록했다.

## 검증

독립된 `BACKPACK_PROFILE_PATH` / `BACKPACK_SETTINGS_PATH`를 사용한다. 실제 1280×720 캡처와 테스트 결과는 `Logs/GuildTabsUI`에 저장한다. 기존 광산 테스트에서 일반 → 광산 → 일반 → 광산으로 전환할 때 배경 리소스도 함께 바뀌는지 확인한다.

전체 PlayMode **114/114 통과** (`final.xml`). 이후 배경 어둡기, 비활성 레벨 업 글자, 잠긴 스테이지 및 소탕 패널의 불투명 처리, 스테이지 분류 버튼과 정보 패널 여백을 보완하고 관련 메뉴 테스트 **31/31 재통과** (`readability.xml`). 전체 실행과 마지막 보완분의 관련 재검증 결과를 구분해 기록한다.

최종 캡처 확인 완료: `CharacterCarouselAllen.png`, `EquipmentAllen.png`, `StageSelectionFive.png`, `OriginMineSelection.png`, `EquipmentDetailsAllen.png`. 캐릭터·장비 배경, 일반/광산 배경 전환, 정보 패널 대비, 잠긴 목록과 비활성 버튼의 가독성을 확인했다. `git diff --check`도 통과했다.

초기 실행의 숨겨진 팝업 버튼 초기화 오류는 `targetGraphic` 명시 연결로 해결했다. 임시 테스트 씬은 정리했으며, 실패/중단 로그 대신 위 성공 결과를 최종 검증 기록으로 사용한다.

후속 가독성 수정(캐릭터 일러스트 패널, 정보 양피지 제거 및 글자색 변경, 장비 툴팁 공통 디자인 복원)은 `Logs/CharacterTooltipPolish/tests.xml`의 관련 PlayMode **31/31 통과**로 검증했다. 같은 폴더의 `CharacterCarouselAllen.png`와 `EquipmentDetailsAllen.png` 실제 1280×720 캡처에서 패널·글자 대비와 툴팁 디자인을 확인했다. 이 실행도 별도 프로필과 설정 경로를 사용했다.

스테이지 포기 팝업에는 메인 화면의 `PrototypeGuildStyle.Surface.Oak` 갈색 패널과 하단 탭과 같은 기본 목재 버튼을 적용했다. 안내문은 크림색이며 크기·배치·포기 및 취소 동작은 유지한다. 별도 프로필·설정 경로를 사용한 `Logs/AbandonPopupUI/tests.xml`에서 일반 스테이지 포기/취소 및 광산 포기 관련 테스트 **2/2 통과**. `AbandonStageConfirmation.png` 실제 화면으로 글자 여백과 버튼 디자인을 확인했다.
