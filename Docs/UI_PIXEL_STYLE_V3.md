# 상점 픽셀 UI 스타일 v3

작성일: 2026-11-13

## 작업 기준

사용자가 승인한 v2의 배치와 1280×720, 16:9 구도를 유지한다. 상점·가방·자유 보관함·출전 캐릭터·적 정보/전투 시작 버튼의 배치를 바꾸지 않고 프레임과 버튼의 시각 스타일을 구체화했다.

이번 작업은 디자인 검토용 시안이다. Unity 런타임 스크립트·씬·데이터·원본 아트는 변경하지 않았다.

## 픽셀 표현 규칙

| 요소 | 규칙 |
|---|---|
| 외곽선 | 짙은 색 2px를 기본으로 형태를 분리 |
| 모서리 | 4px씩 꺾이는 8px 계단형 모서리, 작은 구성 요소는 4px 절삭 |
| 밝은 면 | 위·왼쪽에 2px 밝은 면과 추가 명암 단계 |
| 어두운 면 | 아래·오른쪽에 어두운 면, 부드러운 흐림 대신 단단한 경계 |
| 황동 장식 | 정사각형 못과 제한된 금색 단계 |
| 가죽 | 갈색 계열 단계색, 작은 체크 질감, 점선 바느질 |
| 가방 칸 | 안으로 들어간 느낌의 2px 명암, 4px 칸 간격 |
| 본문·수치 | 읽기 쉬운 한글/숫자를 유지하고 픽셀 장식과 분리 |

가방 표시 격자는 296×296에 46px 칸 6개와 4px 간격 5개로 구성한다. 아이템 표시 위치는 50px 단위여서 내부 경계가 정수 좌표에 맞는다. 이는 시안 표시 규격이며 기존 Unity의 논리적 6×6 배치 규칙을 변경한 것이 아니다.

## 버튼 상태

- 기본: 위쪽 밝은 면과 아래쪽 받침으로 돌출감을 준다.
- 호버: 테두리와 버튼 면을 밝히되 금색 주 행동/청록색 보조 행동의 구분을 유지한다.
- 눌림: 3px 내려앉고 위쪽에 안쪽 그림자를 표시한다.
- 비활성: 불투명도를 낮추는 대신 회색 계열 면·약한 대비·흐린 글자로 표시하고 실제 클릭을 막는다.
- 키보드 포커스: 별도 밝은 외곽선을 유지한다.

시안의 `버튼·칸 상태` 탭에서 전투 시작과 적 정보 버튼의 네 상태를 같은 크기로 비교할 수 있다. 버튼을 직접 호버하거나 눌러도 상태가 바뀐다.

## 아이템과 가방 상태

- 빈 칸: 어두운 안쪽 면.
- 선택: 밝은 금색 테두리.
- 배치 가능: 초록색과 확인 표시.
- 배치 불가: 붉은색과 X 표시.
- 상품 유지 잠금: 상품 테두리·배경·잠금 아이콘을 함께 강조.
- 할인: 작은 픽셀 라벨, 기존 가격 취소선, 할인 가격을 분리.

배치 가능/불가 표시는 구성 요소 비교 화면에서 검토한다. 이번 시안은 전체 드래그 배치 규칙을 실행하는 게임 구현이 아니다.

## 적 정보 팝업

현재 게임과 동일하게 상점의 적 정보 버튼으로 연다. 팝업의 652×454 구도, 적 이름·아트·체력·6×6 가방, 팝업 중 배경 입력 차단, 닫기/ESC/배경 클릭을 유지했다. 팝업과 상대 가방에도 같은 픽셀 테두리를 적용했다.

## 검증

- 실제 브라우저에서 상점·적 정보 팝업·구성 요소 비교를 1280×720로 렌더링하고 시각 확인했다.
- 기본과 호버의 색상 차이, 실제 마우스 누름의 3px 이동, 비활성 버튼, 탭 전환, 모달의 배경 입력 차단을 확인했다.
- 대화창 너비 1024/736/320에서 16:9 축소와 가로 넘침 없음을 확인했다. 좁은 화면에서는 PC 구도를 유지하기 위해 글자도 함께 축소된다.
- 시안 스크립트 오류와 중복 ID가 없음을 확인했다.

## 이후 Unity 적용 시

디자인이 확정되면 공통 패널·주 행동/보조 행동 버튼·슬롯의 프리팹 또는 생성 함수를 정리하고 상태별 시각값을 연결한다. 픽셀 테두리는 크기가 달라져도 일정하게 유지되도록 분리하고, 실제 게임 해상도에서 드래그 판정과 툴팁 경계를 검증한다. 이번 단계에서 해당 게임 구현까지 진행한 것은 아니다.
