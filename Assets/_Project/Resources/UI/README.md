# Critical damage icon

`CriticalDamageSource.png` is the user-provided 72×72 WebP decoded as a lossless PNG.
Its RGB and alpha pixels have not been recolored, redrawn, cropped, or resized.

Source: https://i.namu.wiki/i/xd_B0eGc7_qAHzXQRgLo-7qbuZboyXkusehYdgtBy92iiYK7M9sqNPPkfhmXycgLaRjuBrDXM2o6lv3fgdjWPQ.webp

`CriticalDamageWhite.mat` uses the source alpha unchanged, ignores the source RGB,
and renders the icon in the same light tint as the other tooltip glyphs.
The original transparent silhouette is therefore preserved exactly.
The common circular frame is still drawn separately by `PrototypeStatIcon`.
