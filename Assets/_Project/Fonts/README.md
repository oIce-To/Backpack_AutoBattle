# Tooltip Korean font

Noto Sans KR, SIL Open Font License 1.1 (see `OFL.txt`).

Source: Noto Sans KR variable font, copyright 2014-2021 Adobe, installed as
`NotoSansKR-VF.ttf`. Official project: https://github.com/notofonts/noto-cjk

`NotoSansKR-Regular.ttf` is the static weight-400 instance, generated with
fontTools varLib.instancer. No characters were removed. The complete Korean
character set remains available for future item descriptions.

Unity uses a dynamic SDF atlas with this bundled source font; runtime text
does not depend on fonts installed on the player's computer. Keep the font
and its license together when redistributing the game.
